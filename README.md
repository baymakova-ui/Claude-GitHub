# Сайт-резюме · Ksenia Baimakova

Многоязычное персональное резюме на чистом HTML / CSS / JavaScript.
Без сборщиков, npm и фреймворков. Открывается в любом браузере и
готово к публикации на **GitHub Pages**.

---

## 📂 Структура проекта

Все файлы лежат в корне репозитория (так требует GitHub Pages):

```
├── index.html       ← сама страница (трогать почти не нужно)
├── style.css        ← все стили
├── main.js          ← логика смены языков и анимаций
├── 404.html         ← страница для GitHub Pages
├── data/
│   ├── ru.json      ← весь текст на русском
│   ├── de.json      ← весь текст на немецком
│   └── en.json      ← весь текст на английском
└── assets/
    ├── photo.jpg    ← фото (можно заменить своим)
    └── photo.svg    ← запасной плейсхолдер
```

---

## ✏️ Как изменить текст на сайте

Весь контент (заголовки, опыт, образование, языки, контакты)
живёт в трёх JSON-файлах в папке `data/`. **HTML и JS трогать не нужно.**

### Шаги (прямо на GitHub, без программ):

1. Открой репозиторий на github.com
2. Зайди в папку `data/`
3. Выбери нужный файл:
   - `ru.json` — для русской версии
   - `de.json` — для немецкой
   - `en.json` — для английской
4. Нажми на иконку **карандаша** (✏️ Edit) в правом верхнем углу
5. Измени нужный текст между кавычками `"..."`
6. Прокрути вниз, нажми зелёную кнопку **Commit changes**
7. Через 1–2 минуты сайт обновится автоматически ✨

## 🧩 Как добавить новое место работы

Открой нужный файл (например `data/ru.json`), найди раздел
`"experience"` → `"items"` и **скопируй один из существующих блоков**:

```json
{
  "period": "Январь 2026 — настоящее время",
  "company": "Immokanzlei GmbH",
  "location": "Баден-Вюртемберг, Германия",
  "role": "Бизнес-ассистент руководителя",
  "industry": "PropTech / Недвижимость",
  "bullets": [
    "Первая обязанность",
    "Вторая обязанность",
    "Третья обязанность"
  ]
}
```

Вставь его **выше** старых записей (хронология идёт сверху вниз —
от свежего к старому). Не забудь поставить запятую `,` между блоками.

То же самое для `"education"` (образование), `"skills"` (навыки),
`"languages"` (языки), `"achievements"` (достижения).

## 📸 Как заменить фото

1. Подготовь своё фото в формате **JPG**, желательно вертикальное
   (например 1200×1500 px), вес — до 500 КБ
2. Открой папку `assets/` на GitHub
3. Нажми **Add file → Upload files**
4. Перетащи новое фото и **переименуй его в `photo.jpg`**
   (или загрузи под старым именем — оно перезапишется)
5. Нажми **Commit changes**

---

## 📄 Как добавить PDF-резюме (для кнопки «Скачать»)

Положи три PDF-файла в папку `assets/` с такими именами:

- `resume-ru.pdf`
- `resume-de.pdf`
- `resume-en.pdf`

Кнопка «Скачать резюме» (правый нижний угол) найдёт их автоматически.

## 🌐 Как переключаются языки

- Кнопки **RU · DE · EN** в правом верхнем углу
- Сайт запоминает выбор в браузере посетителя
- При первом заходе язык определяется автоматически по браузеру
- Можно отправлять прямые ссылки:
  - `сайт.com/#ru` — откроется сразу на русском
  - `сайт.com/#de` — на немецком
  - `сайт.com/#en` — на английском

Удобно при отправке резюме в немецкие или международные компании.

## 🚀 Как опубликовать на GitHub Pages

1. На GitHub зайди в **Settings → Pages**
2. В разделе **Source** выбери ветку `main` и папку `/ (root)`
3. Нажми **Save**
4. Через 1–2 минуты сайт будет доступен по адресу
   `https://<твой-логин>.github.io/<имя-репозитория>/`

## 🛠 Локальный просмотр

Чтобы проверить сайт у себя на компьютере:

**Самый простой способ:** просто дважды кликнуть по `index.html`.
Большинство функций будут работать.

**Если JSON-файлы не загружаются** (некоторые браузеры блокируют
`fetch` локально), запусти простой сервер:

```bash
# Python 3
python3 -m http.server 8000
```

Затем открой `http://localhost:8000` в браузере.

## 🎨 Цвета и шрифты

Если захочется поменять оформление — вверху файла `style.css`
есть переменные:

```css
:root {
  --color-bg: #f7f5f0;     /* фон страницы */
  --color-navy: #1a2744;   /* основной тёмный */
  --color-gold: #b8966e;   /* золотой акцент */
  --color-text: #1e1e1e;   /* основной текст */
  --color-muted: #8a8680;  /* приглушённый текст */
}
```

Шрифты подключены из Google Fonts:
**Cormorant Garamond** (заголовки) и **Inter** (текст).

## 📞 Контакты в шапке

Email и телефон тоже редактируются в JSON, в разделе `"contact"`:

```json
"contact": {
  "email": "baymakova.ksenya@mail.ru",
  "phone": "+7 916 127 5862"
}
```

При нажатии на email открывается почтовый клиент,
при нажатии на телефон — звонок (на мобильном).

## ❓ Если что-то сломалось

- **Сайт не открывается** → проверь, что в JSON все кавычки `"`
  и запятые `,` на месте. Один пропуск — и страница не загрузится.
  Можно проверить файл на сайте https://jsonlint.com
- **Фото не появилось** → убедись, что файл называется именно
  `photo.jpg` (с маленькой буквы) и лежит в `assets/`
- **Текст не меняется** → подожди 1–2 минуты, GitHub Pages
  обновляется не мгновенно. Также попробуй обновить страницу
  с очисткой кэша: `Ctrl+Shift+R` (Windows) или `Cmd+Shift+R` (Mac)
