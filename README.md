# Сайт-резюме · Ksenia Baimakova

Многоязычное персональное резюме на чистом HTML / CSS / JavaScript.
Без сборщиков, npm и фреймворков. Открывается в любом браузере.

> 💡 **Главное:** этот сайт полностью самостоятельный. Чтобы менять
> текст, фото и контакты, тебе **не нужны** ни Claude, ни подписки,
> ни знание программирования. Всё редактируется в простых текстовых
> файлах. Эта инструкция проведёт тебя за руку по каждому шагу.

---

## 📂 Что где лежит

```
├── index.html       ← сама страница (трогать НЕ нужно)
├── style.css        ← оформление: цвета, шрифты (только для дизайна)
├── main.js          ← логика (трогать НЕ нужно)
├── 404.html         ← служебная страница
├── data/            ← 👈 ВЕСЬ ТЕКСТ ЗДЕСЬ
│   ├── ru.json      ← русская версия
│   ├── de.json      ← немецкая версия
│   └── en.json      ← английская версия
└── assets/
    ├── photo.jpg    ← твоё фото
    └── photo.svg    ← запасная картинка
```

**Запомни одно:** почти всё, что ты захочешь поменять, находится
в папке `data/` в трёх файлах. Остальное можно не трогать.

## ✏️ Базовое правило JSON (прочитай один раз)

Файлы `ru.json` / `de.json` / `en.json` устроены как пары
**«название»: «значение»**. Менять можно только текст
**внутри кавычек справа**:

```json
"title": "Бизнес-ассистент высшей квалификации"
            ↑ вот это можно и нужно менять ↑
```

❗️ **Три железных правила, чтобы сайт не сломался:**
1. Не трогай слова слева от двоеточия (`"title"`, `"company"` и т.д.)
2. Не удаляй **кавычки** `"` вокруг текста
3. Не удаляй **запятые** `,` в конце строк

Если внутри текста нужны кавычки — используй « » (как в «Der Schlüssel»),
а не обычные `"`.

✅ **После любого изменения** скопируй весь текст файла и вставь на
[jsonlint.com](https://jsonlint.com) → нажми «Validate JSON».
Если напишет *"Valid JSON"* — всё в порядке. Это страховка от опечаток.

## 📝 Задача 1. Поменять текст (например, должность)

Допустим, хочешь сменить должность в русской версии.

1. Открой файл `data/ru.json`
2. Найди строку (примерно в начале файла):

   **Было:**
   ```json
   "title": "Бизнес-ассистент высшей квалификации",
   ```
   **Стало:**
   ```json
   "title": "Старший бизнес-ассистент",
   ```
3. Сохрани файл
4. Повтори то же самое в `de.json` и `en.json` (на нужном языке),
   если хочешь, чтобы изменилось во всех версиях
5. Залей обновления в Netlify (см. раздел 🚀 ниже)

---

## 📝 Задача 2. Добавить новое место работы

1. Открой `data/ru.json`, найди раздел `"experience"` → `"items"`
2. Скопируй **целиком один блок** в фигурных скобках `{ ... }`
3. Вставь копию **в самый верх списка** (свежая работа — сверху)
4. Поставь запятую `,` после закрывающей скобки `}`, чтобы отделить
   от следующего блока
5. Замени текст внутри на свой

**Шаблон нового блока:**
```json
{
  "period": "Март 2026 — настоящее время",
  "company": "Название компании",
  "location": "Город, Страна",
  "role": "Твоя должность",
  "industry": "Сфера деятельности",
  "bullets": [
    "Первая обязанность или достижение",
    "Вторая обязанность",
    "Третья обязанность"
  ]
}
```

**Как должно выглядеть** (две работы подряд):
```json
"items": [
  {
    "period": "Март 2026 — настоящее время",
    "company": "Новая компания",
    "role": "Новая должность",
    "location": "Берлин, Германия",
    "industry": "IT",
    "bullets": ["Делала то", "Делала это"]
  },
  {
    "period": "Январь 2026 — Февраль 2026",
    "company": "Immokanzlei GmbH",
    ...
  }
]
```
👆 Обрати внимание на запятую между `}` и `{`.

> Не забудь добавить эту же работу в `de.json` и `en.json`
> на соответствующем языке.

## 📝 Задача 3. Поменять достижения (цифры)

Раздел `"achievements"` → `"items"`. Каждая цифра — это блок:

```json
{ "number": "6000", "suffix": "+", "label": "клиентов в базе" }
```
- `number` — сама цифра (она будет красиво «накручиваться» при прокрутке)
- `suffix` — что приписать после (например `+`, `ч`, или пусто `""`)
- `label` — подпись под цифрой

**Пример:** добавить «10 лет опыта»:
```json
{ "number": "10", "suffix": "", "label": "лет опыта" }
```

## 📝 Задача 4. Изменить уровни языков

Раздел `"languages"` → `"items"`:
```json
{ "name": "Немецкий", "level": "B2", "percent": 75 }
```
- `name` — название языка
- `level` — подпись (C1, B2, «Родной» и т.д.)
- `percent` — длина шкалы от 0 до 100 (на сколько заполнится полоска)

**Пример:** повысить немецкий до C1:
```json
{ "name": "Немецкий", "level": "C1", "percent": 90 }
```

## 📝 Задача 5. Изменить навыки (лента)

Раздел `"skills"` → `"list"` — это просто список в кавычках через запятую:
```json
"list": [
  "KPI-автоматизация",
  "Agile / Trello",
  "Новый навык"
]
```
Добавляй или удаляй строки. У каждой строки в кавычках — запятая в конце,
**кроме самой последней**.

## 📸 Задача 7. Заменить фото

1. Подготовь фото в формате **JPG**, вертикальное
   (примерно 1200×1500 px), весом до ~500 КБ
2. Переименуй его точно в **`photo.jpg`** (маленькими буквами)
3. Положи в папку `assets/`, заменив старый файл
4. Залей в Netlify

> Если фото называется иначе (например `foto.JPG`) — сайт его не найдёт.
> Имя должно быть строго `photo.jpg`.

## 🚀 Как залить изменения в Netlify

### Если ты загружала сайт перетаскиванием папки:
1. Зайди на [app.netlify.com](https://app.netlify.com) → открой свой сайт
2. Вкладка **Deploys**
3. Внизу есть зона **«Drag and drop your site folder here»**
4. Перетащи туда **обновлённую папку целиком**
5. Через несколько секунд сайт обновится ✨

### Если сайт подключён к GitHub:
- Просто сохрани изменения на GitHub (Commit) — Netlify обновит
  сайт автоматически за 1–2 минуты

## 🛠 Как посмотреть сайт у себя перед загрузкой

**Простой способ:** дважды кликни по `index.html` — откроется в браузере.
Большинство всего заработает.

**Если текст не подгружается** (некоторые браузеры блокируют чтение
JSON с диска), запусти простой сервер. Открой терминал в папке сайта:
```bash
python3 -m http.server 8000
```
Затем открой в браузере `http://localhost:8000`.

## 🎨 Для смелых: поменять цвета

Цвета собраны вверху файла `style.css`. Меняй значения после `#`:
```css
:root {
  --color-bg: #f7f5f0;     /* фон страницы (тёплый белый) */
  --color-navy: #1a2744;   /* тёмно-синий */
  --color-gold: #b8966e;   /* золотой акцент */
  --color-text: #1e1e1e;   /* основной текст */
  --color-muted: #8a8680;  /* приглушённый текст */
}
```
Подобрать новый цвет можно на [htmlcolorcodes.com](https://htmlcolorcodes.com) —
скопируй код вида `#aabbcc` и вставь.

Шрифты: **Cormorant Garamond** (заголовки) и **Inter** (текст),
подключены из Google Fonts.

## ❓ Если что-то сломалось

| Проблема | Что делать |
|---|---|
| **Сайт пустой / не загружается** | Проверь JSON на [jsonlint.com](https://jsonlint.com) — скорее всего пропущена кавычка или запятая |
| **Текст не поменялся** | Подожди 1–2 минуты после загрузки и обнови страницу с очисткой кэша: `Ctrl+Shift+R` (Windows) или `Cmd+Shift+R` (Mac) |
| **Фото не появилось** | Файл должен называться строго `photo.jpg` и лежать в `assets/` |
| **Сломалось после правки** | Открой [jsonlint.com](https://jsonlint.com), вставь файл — он подсветит строку с ошибкой |

> 🆘 **Запасной вариант:** перед серьёзными правками сделай копию
> папки `data/` себе на компьютер. Если что-то пойдёт не так —
> просто верни старые файлы обратно.
